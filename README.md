# mc-shaders

Build prompt for a high-end Minecraft shader pack (Iris/OptiFine): ray-traced water
reflections, volumetric god rays, wind-animated foliage, custom sun/moon and sky.

See **[SHADER_PROMPT.md](SHADER_PROMPT.md)** — full prompt, short version, follow-up
prompts for debugging/perf/look-dev, and a bonus trailer-render prompt.

An experimental initial implementation is in **[Lumen/](Lumen/README.md)**. It has not
been tested in-game; see its README for implemented effects and limitations.
